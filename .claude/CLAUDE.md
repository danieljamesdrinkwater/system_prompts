# AI System Prompts Collection

This repository contains system prompts from various AI providers, organized by company.

## Structure
- `Anthropic/` - Claude model system prompts
- `OpenAI/` - GPT and o-series model system prompts
- `Google/` - Gemini model system prompts
- `MetaAI/` - Meta AI / Llama system prompts
- `xAI/` - Grok system prompts
- Root-level files are miscellaneous or uncategorized prompts

## Conventions
- File names follow the pattern: `ModelName-Version` or `ModelName-Version-YYYYMMDD`
- Files are plain text
- New prompts go in the appropriate company directory

## Session Guidelines
- This is primarily a read-only reference repository. Most tasks involve reading, comparing, and searching prompts.
- Preserve existing file naming conventions when editing.
- Do not delete existing prompt files without explicit confirmation.
- Keep responses concise — this project is configured for voice-controlled VR usage.
- A safety guard hook blocks destructive commands automatically.
